# Từ Vựng Mỗi Ngày

Web học 5.446 mục từ, trắc nghiệm nghĩa, nghe viết, gợi ý và ôn tập.

## Chạy trên máy

Chạy `python -m http.server 8000` rồi mở http://localhost:8000.

## GitHub Pages

Đưa toàn bộ các file vào thư mục gốc repository. Vào Settings > Pages > Deploy from a branch > main > / (root) > Save.

Tiến độ lưu trên trình duyệt, âm thanh dùng speechSynthesis. Phần ví dụ AI mở ChatGPT riêng.

Dữ liệu từ tài liệu người dùng cung cấp; chỉ chia sẻ dữ liệu khi bạn có quyền.
